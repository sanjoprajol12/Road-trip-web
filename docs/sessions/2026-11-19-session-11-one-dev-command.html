Session 11: API and public website from one command

2026-11-19 · Claude Code (Opus 5.5) · Nothing committed · No application code changed

Objective

Owner: start the Laravel API and the public website with cd web && npm run dev, without entering frontend/, keeping the Vue app where it is, the staff portal independent and the separate commands working.

What changed

  • web/package.json: dev = port guard, then concurrently 10.0.7 (via npx, as composer dev already used it; pinned, no new dependency) running php artisan serve --port=8010 --tries=1, the queue listener, the log tail and the public Vite server on 5180 with --kill-others. Also dev:api (= composer dev) and dev:web.
  • web/scripts/dev-ports-free.mjs: refuses to start when 8010 or 5180 is taken, so no second Laravel (which would otherwise move to another port) or Vite server starts.
  • Docs: README.md, DEVELOPMENT_SETUP.md, CLAUDE.md, handoff.md.
