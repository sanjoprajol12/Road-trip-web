Session 17 follow-up: places.review for moderators

2026-11-20 · Claude Code (Opus 5.5) · Nothing committed · One additive migration · Owner approval given in the session brief

Owner approval and scope

The built-in moderator role may review rider-submitted places and corrections. It must not receive place management or publication rights. Nothing else was changed: no other role, no places.manage or places.publish for moderators, no MFA, no PostGIS, no dependencies.

Roles: moderator 14 to 15 permissions (adds places.review only). Administrator: all keys, unchanged. Custom roles: unchanged; the dev role tester was verified untouched.

Backend behaviour

  • One shared action, DecidePlace, serves both endpoints. It locks the row and re-reads its status, so stale or repeated decisions get 422. It refuses the reviewer's own suggestion and corrections, requires a reason to reject or request changes, never edits rider text, and writes audit rows marked via review|lifecycle.
  • The review routes reach rider suggestions only: staff-created places answer 404, and lifecycle decisions are refused with 422. Corrections are locked the same way.

Frontend behaviour

The Places item is visible with manage or review. A moderator sees only the "Rider suggestions" and "Corrections" tabs: read-only details, a preview on the website, history, and approve, ask for changes or reject with a required reason. There are no create, edit, publish, unpublish or archive controls. Administrators keep everything.

Discovered issue: session 17 was misreported

Session 17's full public E2E run had 3 failures, not "123 passed, 3 skipped". Session 17 changed the wording "from the route line" on the destination page, and the destination-map spec failed on all three projects. The failures were missed because only the last lines of the output were read, and the pipe's exit code was 0. The wording is restored, the full suite passes now, and the session 17 report carries a correction notice. From now on the full filtered output is read before results are reported.
