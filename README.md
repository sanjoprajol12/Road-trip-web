# My Ride Nepal: web

Motorcycle travel in Nepal. This repository holds:

- the **Laravel 12 API** (`app/`, `routes/api.php`, `database/`): authentication, authorization, business rules, uploads, audit log;
- the **public site and rider platform**, a Vue 3 + TypeScript SPA in `resources/app` (built into `public/app` and served by Laravel);
- project documentation in `docs/`;
- `supabase/config.toml`, used only to run a local PostgreSQL and the Mailpit mail catcher.

The staff application is a separate repository (Road-trip-admin, folder `../admin`).

## Quick start
```sh
composer install && pnpm install
cp .env.example .env && php artisan key:generate      # then set DB_PASSWORD and DB_MIGRATION_PASSWORD
pnpm db:start && pnpm db:setup
php artisan migrate --database=pgsql_owner && php artisan db:seed
php artisan serve --port=8010                          # API (and built SPA)
pnpm dev                                               # SPA with hot reload on http://127.0.0.1:5180
```
Full guide: `docs/architecture/DEVELOPMENT_SETUP.md`. API reference: `/docs` (generated by Scribe).
